# Contributing to ZHIXI

Thank you for your interest in contributing to ZHIXI (知悉)! This document provides guidelines and information for contributors.

## Code of Conduct

By participating in this project, you agree to maintain a respectful and inclusive environment for everyone.

## How to Contribute

### Reporting Bugs

1. Check [existing issues](https://github.com/tensely0228/ZHIXI/issues) first
2. Use the bug report template
3. Include: steps to reproduce, expected behavior, actual behavior, and your environment details

### Suggesting Features

1. Check [existing issues](https://github.com/tensely0228/ZHIXI/issues) first
2. Use the feature request template
3. Explain the problem your feature solves, not just the feature itself

### Submitting Changes

1. Fork the repository
2. Create a feature branch: `git checkout -b feature/description`
3. Make focused, atomic commits with clear messages
4. Test your changes
5. Push to your fork and submit a Pull Request

### Commit Message Format

```
Type: Short description

Types:
- feat: New feature or capability
- docs: Documentation changes
- fix: Bug fix
- refactor: Code restructuring
- example: New examples
- chore: Maintenance tasks
```

## Skill File Guidelines

When modifying `SKILL.md`:

- Preserve the four-stage structure (知己 → 问己 → 明需 → 洞意)
- Keep the YAML frontmatter intact
- Test the modified skill in your AI environment before submitting
- Ensure knowledge fragment format remains compatible
- Do not add external API dependencies

## Documentation Guidelines

- Use clear, concise language
- Include examples where possible
- Keep bilingual content (Chinese + English) when modifying core docs
- Use Mermaid for diagrams

## Questions?

Open an issue with the `question` label, or start a discussion.

---

Thank you for helping make ZHIXI better for everyone!
