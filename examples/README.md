# Examples

Real-world usage examples of the ZHIXI (知悉) thinking framework.

## Available Examples

### [From Vague Idea to Action Plan](./vague-idea-to-action.md)

**Best for:** Understanding the complete four-stage flow in a practical scenario.

Walks through a personal productivity use case — from "I want a reading note tool" to a structured requirements baseline, decomposed capability units, and knowledge fragments. Demonstrates all four stages (知己 → 问己 → 明需 → 洞意) with concrete outputs.

### [Knowledge Fragment Lifecycle](./knowledge-fragment-example.md)

**Best for:** Understanding how knowledge capture works across sessions.

Shows how ZHIXI produces knowledge slots in Stage 3, then generates structured knowledge fragments in Stage 4. Includes examples of technical findings and decision rules with proper confidence scoring.

## Reading Order

If you're new to ZHIXI, we recommend:

1. Read the [README](../README.md) first for the overview and quick start
2. Read [From Vague Idea to Action Plan](./vague-idea-to-action.md) to see the framework in action
3. Read [Knowledge Fragment Lifecycle](./knowledge-fragment-example.md) to understand how knowledge accumulates
