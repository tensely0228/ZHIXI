# Examples

Real-world usage examples of the ZHIXI (知悉) thinking framework.

## Available Examples

### [From Vague Idea to Action Plan](./vague-idea-to-action.md)

**Best for:** Understanding the complete four-stage flow in a practical scenario.
**Complexity:** Beginner

Walks through a personal productivity use case — from "I want a reading note tool" to a structured requirements baseline, decomposed capability units, and knowledge fragments. Demonstrates all four stages (知己 → 问己 → 明需 → 洞意) with concrete outputs.

### [Knowledge Fragment Lifecycle](./knowledge-fragment-example.md)

**Best for:** Understanding how knowledge capture works across sessions.
**Complexity:** Beginner

Shows how ZHIXI produces knowledge slots in Stage 3, then generates structured knowledge fragments in Stage 4. Includes examples of technical findings and decision rules with proper confidence scoring.

### [Team Process Improvement](./team-process-improvement.md)

**Best for:** Seeing ZHIXI handle conflicting constraints, stakeholder resistance, and tool tradeoffs.
**Complexity:** Intermediate

A 10-person team wants to adopt code review but faces resistance, time pressure, and tool disputes. Demonstrates how ZHIXI navigates multi-stakeholder scenarios with explicit tradeoff analysis and graded implementation strategies.

### [Advanced Knowledge Fragments](./advanced-knowledge-fragments.md)

**Best for:** Understanding all `kind` types and the knowledge fragment format in depth.
**Complexity:** Advanced

A technology migration decision (monolith → microservices) producing four different fragment types: `risk_boundary`, `open_question`, `decision_rule`, and `deprecated`. Shows how different dimensions of a decision are captured as distinct, cross-referenced fragments.

## Reading Order

If you're new to ZHIXI, we recommend:

1. Read the [README](../README.md) first for the overview and quick start
2. Read [From Vague Idea to Action Plan](./vague-idea-to-action.md) to see the framework in action
3. Read [Knowledge Fragment Lifecycle](./knowledge-fragment-example.md) to understand how knowledge accumulates
4. Read [Team Process Improvement](./team-process-improvement.md) to see ZHIXI handle real-world complexity
5. Read [Advanced Knowledge Fragments](./advanced-knowledge-fragments.md) to master the fragment format
